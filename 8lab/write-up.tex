\section{Part 3}
The functional dependencies for each of the tables also happen to be the primary keys, wow!
In table People, id functionally determines all other columns.
In table Actors, pid functionally determines all other columns.
In table Directors, pid functionally determines all other columns.
In table Movies, MPAA Number functionally determines all other columns.
In table MovieCasts, the primary key is all the columns director, actor, and MPAA Number of the 
    table so there are no depdedant columns.
In table MovieSales, id functionally determines all other columns.
\section{Part 4}
\begin{verbatim}
-- Select which gets the names of all direcotrs who have worked with Roger
--     Moore on any movie
SELECT directorP.firstName, directorP.lastName
FROM People directorP
INNER JOIN Directors d ON directorP.id=d.pid
INNER JOIN MovieCasts m ON d.pid = m.director
INNER JOIN People actorP ON actorP.id = m.actor
WHERE actorP.firstName = 'Roger' AND
      actorP.lastName  = 'Moore'
;

\end{verbatim}
